# DevToolkit Hub

A comprehensive web-based developer utilities suite featuring a JSON formatter and validator, API tester, encoders/decoders (Base64, URL, JWT), and hash generators.

## Features
- JSON Formatter, Minifier & Validator
- Lightweight API Request Tester
- Encoders & Decoders (Base64, URL, JWT payload inspector)
- Hash & UUID v4 Generators
- Local History & SQLite Persistence
- Dark / Light Mode
